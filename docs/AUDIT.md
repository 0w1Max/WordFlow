# Технический аудит WordFlow

База проверки: GitHub `0w1Max/WordFlow`, default branch `dev`,
коммит `4424ba3816569862d30e360909fcd8bd7a512dba`. Проверено 6 ноября 2026.
Изменения подготовлены локально, без изменения рабочей базы или деплоя.

## Исправления

| Область            | Проблема                                                                     | Решение                                                                                |
| ------------------ | ---------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| HTML               | Кавычки не экранировались в атрибутах форм                                   | Общий независимый HTML-encoder, проверка вредоносного ввода в браузере                 |
| JWT                | Известный запасной секрет и отсутствие отзыва сессий                         | Проверка production-конфигурации, случайный dev-ключ, версия сессии в БД, только HS256 |
| Гостевой аккаунт   | Claim позволял менять реквизиты обычного пользователя                        | Условный UPDATE только `is_guest=1`, отзыв старого гостевого JWT                       |
| Пароль             | Повторное конкурентное использование reset-token; срок сравнивался как текст | Атомарный UPDATE с проверкой hash и datetime, отзыв старых сессий                      |
| Ссылки сброса      | Домен строился из непроверенного Host                                        | Явный `APP_ORIGIN`                                                                     |
| Запросы            | Неверные типы приводили к 500; не было проверки origin                       | Проверки JSON, ID, полей, длины, origin и fetch metadata                               |
| Категории          | Можно привязать чужую категорию; удаление неатомарно                         | Проверка владельца в сервисе и SQL-trigger, транзакционный batch удаления              |
| Даты               | ISO и SQLite timestamp сравнивались лексикографически                        | SQL datetime при сравнении, явный UTC в API                                            |
| Повторение         | Ошибка сохранения молча пропускала слово; двойной клик                       | Сохранение позиции при ошибке и защита от повторной отправки                           |
| Ударение           | Индекс смещался после trim; picker не подключался при открытии редактора     | Необрезанный текст до сервера, UTF-16 offsets, инициализация обработчика               |
| Навигация          | Запоздалый ответ мог перерисовать другую страницу                            | Отдельный DOM-корень маршрута, проверки актуальности, обработка ошибок router          |
| Конфиденциальность | Содержимое слов в логах; `.env` попадал в образ                              | Удалены отладочные listeners, исключены секреты из Docker, очищен контекст Sentry      |
| Зависимости        | Не было lockfile; npm обнаруживал 33 уязвимых пакета                         | Обновления, lockfile, `npm ci`, встроенный Node watch вместо nodemon                   |
| Структура          | Смешение типографики, форм, иконок и HTML в dom.js                           | Модули по ответственности; отдельные карточки; миграции отдельно от клиента            |
| Качество           | Избыточные исторические комментарии; 9 тестов падали на Windows              | Краткие комментарии об ограничениях, переносимый import, ESLint, Prettier, CI          |

## Проверки и границы

- Unit/API тесты используют изолированный `file::memory:`; включают конкурентный
  сброс пароля, истечение ссылки в текущий день и изоляцию пользователей.
- Браузерные сценарии выполняются в Chrome через Playwright.
- Проверены синтаксис, ESLint, форматирование, npm audit и diff whitespace.
- Docker CLI в среде отсутствует: Dockerfile проверен статически, образ не собирался.
- Рабочие Turso, Resend, Sentry и Vercel не вызывались. Их настройки и реальную
  доставку письма нужно проверить на staging перед production-релизом.
- Счётчики rate limit остаются в памяти процесса. На нескольких инстансах нужен
  общий Redis-store или ограничение на уровне платформы; локальный лимит не глобальный.
- Для ESLint и `@eslint/config-array` явно задан исправленный `minimatch >=11.0.1`:
  штатная транзитивная версия затронута GHSA-g3hv-75wg-m249. Совместимость проверяется lint в CI.
- Существующие бесхозные данные и чужие связи из старой БД автоматически
  не переприсваиваются. Их исправление требует проверки настоящего владельца.
- Список всех слов остаётся без пагинации для сохранения текущего API/UI;
  при большой коллекции потребуется отдельное изменение контракта.
- Logout удаляет cookie в браузере. Украденный JWT живёт до истечения срока
  или смены пароля; поштучный отзыв устройств потребует серверного реестра сессий.
